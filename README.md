## 🚀 Key Architectural Features

- **🛡️ Hardened Enterprise Core:** Built with rigorous error handling, atomic file operations, and automated configuration backups (`.bak`) to guarantee zero shell corruption.
- **⚡ Dual Syntax Support:** Seamlessly execute native CLI commands or your preferred custom shorthand syntax (`set splogo` / `out splogo`).
- **🔍 Deep System Diagnostics (`doctor`):** Instantly audits core binary dependencies (`figlet`, `toilet`, `ruby`, `lolcat`, `fish`) to ensure absolute subsystem integrity.
- **🎨 Rich Terminal UI:** Powered by `rich` and `click`, featuring live spinners, progress feedback, and beautifully structured status panels.
